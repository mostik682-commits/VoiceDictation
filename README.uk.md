# VoiceDictation

**Диктовка голосом у будь-яке вікно Windows.** Затисни клавішу, говори, відпусти — текст з'явиться там, де стоїть курсор: Word, браузер, Telegram, пошта — будь-де.

## Можливості

- **Диктовка в будь-якому вікні.** Затисни **правий Ctrl**, говори, відпусти. Розділові знаки, великі літери, абревіатури (ЗСУ, ДСНС…) і помилки розпізнавання виправляються самі, текст вставляється в курсор. Буфер обміну після цього повертається як був.
- **18 мов розпізнавання.** *Авто* (сервіс сам визначає мову кожної фрази), українська, російська, англійська, польська, німецька, французька, іспанська, італійська, португальська, чеська, словацька, румунська, болгарська, турецька, арабська, японська, китайська. Перемикається в один клік з меню значка біля годинника.
- **Меню для виділеного тексту** (`Ctrl + Пробіл`): *прибрати воду*, *діловий стиль*, *товариський стиль з емодзі* або **свій варіант голосом** — «переклади англійською», «скороти до двох речень», «зроби списком»… `Ctrl + Z` повертає як було.
- **Свій словник** для назв, прізвищ і абревіатур, які треба писати саме так.
- **Безкоштовно.** Потрібен лише твій ключ: [Groq](https://console.groq.com/keys) — безкоштовно (з денними лімітами), [OpenAI](https://platform.openai.com/api-keys) — платно (≈ $0,36 за годину диктовки), найточніше.
- **Без прав адміністратора, без акаунта, без телеметрії.** Звук іде лише до обраного тобою сервісу з твоїм ключем. Налаштування й ключ лежать на твоєму ПК у `%APPDATA%\VoiceDictation`.

## Встановлення

1. Завантаж **`VoiceDictation-Setup.exe`** зі [сторінки останнього релізу](https://github.com/mostik682-commits/VoiceDictation/releases/latest) і запусти (Далі → Встановити → Готово).
2. Windows може показати синє вікно «Windows захистила ваш ПК» — інсталятор не має платного цифрового підпису. Натисни **Докладніше → Виконати однаково**.
   Якщо **Smart App Control** увімкнено, Windows може заблокувати непідписані програми — див. [нижче](#smart-app-control).
3. Під час першого запуску програма спитає, який сервіс використовувати. Обери **Groq** (безкоштовно), створи ключ на <https://console.groq.com/keys>, натисни **Вставити** → **Зберегти**.
4. Відкрий Блокнот, затисни **правий Ctrl**, скажи фразу, відпусти.

Немає правого Ctrl (буває на ноутбуках)? Клік по значку мікрофона біля годинника → «Налаштування» → «Гарячі клавіші».

### Встановлення з ШІ-агентом

Користуєшся Claude Code, Codex чи іншим агентом? Відкрий цей репозиторій (або просто вставте посилання на нього) і напиши **«Допоможи встановити VoiceDictation»**. Агент прочитає [`AGENTS.md`](AGENTS.md) / [`CLAUDE.md`](CLAUDE.md) і проведе за кроками, ніколи не просячи вставляти ключ у чат.

## Як користуватися

| Дія | Як |
| --- | --- |
| Диктовка | Затисни **правий Ctrl**, говори, відпусти |
| Переписати виділений текст | Виділи текст → `Ctrl + Пробіл` → обери пункт (клік, стрілки + Enter або цифра 1–4) |
| Свій варіант голосом | `Ctrl + Пробіл` → пункт 4 → скажи, що зробити, напр. «Переклади англійською» |
| Скасувати зміну | `Ctrl + Z` |
| Змінити мову | Значок біля годинника → **Мова** |
| Налаштування | Клік по значку → клавіші, сервіси й ключі, мова, словник |

Повна інструкція: [`installer/Як користуватися.txt`](installer/%D0%AF%D0%BA%20%D0%BA%D0%BE%D1%80%D0%B8%D1%81%D1%82%D1%83%D0%B2%D0%B0%D1%82%D0%B8%D1%81%D1%8F.txt).

### Файл налаштувань

`%APPDATA%\VoiceDictation\config.json` (зміни підхоплюються за кілька секунд):

| Ключ | Що означає |
| --- | --- |
| `language` | `""` — автовизначення, або код: `uk`, `ru`, `en`, `pl`, `de`, … |
| `provider` / `text_provider` | `openai` або `groq` для розпізнавання / переписування |
| `dictionary` | список термінів, які треба писати точно |
| `cleanup_prompt` | правила автоматичної чистки після диктовки |
| `command_menu` | пункти меню `Ctrl + Пробіл` (`title`, `prompt`, `done`) |

## Мова: Авто чи конкретна?

*Авто* найзручніше, якщо диктуєш різними мовами. Якщо завжди диктуєш однією — обери її явно: короткі фрази (одне-два слова) і шумні записи так розпізнаються надійніше. В режимі *Авто* речення зі змішаною мовою розпізнається як одна мова, тож іншомовні слова можуть бути записані не тими літерами.

## Smart App Control

*Smart App Control* у Windows 11 може блокувати будь-який непідписаний інсталятор. Перевір: **Безпека Windows → Керування програмами та браузером → Параметри Smart App Control**. «Вимкнено» й «Оцінювання» — усе гаразд. Якщо «Увімкнено» — запусти програму [з вихідного коду](#запуск-з-вихідного-коду). (Вимкнення Smart App Control незворотне без перевстановлення Windows — це рішення лише твоє.)

## Запуск з вихідного коду

Потрібен Python 3.10+ для Windows.

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python dictation.py
```

## Збірка інсталятора

Потрібні Python 3.10+ і [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
py -3 -m venv .buildvenv
.buildvenv\Scripts\python -m pip install -r requirements.txt pyinstaller
.buildvenv\Scripts\python installer\build_installer.py
# результат: installer\Output\VoiceDictation-Setup.exe
```

## Якщо щось не так

- **Текст не з'являється / тиша:** Параметри → Система → Звук → твій мікрофон → гучність введення ≈ 75 %. Також: Конфіденційність і захист → Мікрофон → дозволити настільним програмам.
- **«Сервіс не прийняв ключ»:** ключ скопійовано не повністю. Створи новий і встав у «Налаштування» → «Сервіси».
- **«Ліміт запитів вичерпано»:** у Groq є ліміти на хвилину й на день. Зачекай або візьми платний ключ OpenAI.
- **Немає значка біля годинника:** він може ховатися під стрілкою **^**.
- **Журнал:** `%APPDATA%\VoiceDictation\dictation.log` (ключів там немає).
